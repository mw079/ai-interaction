Connect OpenAI

Demo mode works without an account. GPT-6 Luna handles short previews while you type. GPT-6.1 Terra creates the longer interactive page only when you click Explore interactively.

Connecting enables live preview: your draft, choices and explicitly selected text are sent through this website’s server to OpenAI after typing pauses. Your key stays in this tab’s memory and is forwarded for these requests; the app does not save it. API charges apply. Each connection is limited to 30 model requests across both stages. No desktop key is accessed.

A workspace, not a waiting room.

Describe an unfinished thought. Correct the interpretation, fill in a missing detail, or work directly on the document. You don’t have to finish one message before contributing again.

Feedforward and inline clarification are inspired by Bruce Liu’s work. This prototype connects them to an editable artifact, explicit selection, reusable visual components and reviewable changes.

Those are established interaction ideas in a new combination—not a claim to have invented a new research paradigm. The question is whether the combination helps people reach what they actually intended.

Demo mode uses a small catalog of examples. Live previews use GPT-6 Luna; full interactive pages use GPT-6.1 Terra. There is no web search, agent file access, computer control, account storage or collaborative sync here yet.
